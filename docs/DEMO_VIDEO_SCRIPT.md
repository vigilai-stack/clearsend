# Demo video script (about 2:45)

Record in desktop Chrome with the on-device model ready (banner at the top). Use only the sample messages.

**0:00-0:20 | The problem**
"Portal messages are where patients tell their clinic what's wrong. Some of those messages shouldn't wait a day for a reply, and some contain things that should never be sent at all. ClearSend checks a message before it goes, and the message never leaves your computer."

**0:20-0:55 | Red flag**
Pick the sample "I've had chest pain since this morning…". Click Check.
Show the red banner: call 911 now.
"This check is fixed rules, not the model. The model can make a message more urgent, but it can never make it less urgent."

**0:55-1:30 | Never-send items**
Pick the sample with the card number. Click Check.
Show "Taken out of your message" and the cleaned text.
"Clinics never need a full card number in a portal message, so it's removed before sending."

**1:30-2:00 | Getting it ready for the care team**
Type: "Please refill my lisinopril 10 mg." Click Check.
Show: goes to Prescription refills, the one-line summary, and "Which pharmacy should it go to?"
"That's the question the clinic would have sent back tomorrow. Now it's answered today."

**2:00-2:30 | On-device vs cloud**
In General question, type "What does prior authorization mean?" and click Ask. It gets an answer.
Then type "I have diabetes, what does my A1C result mean?" and click Ask. It stays on the computer.
"General questions can use the cloud. Anything about you stays here."

**2:30-2:45 | Close**
"Firebase AI Logic in hybrid mode, App Check, Remote Config, and fixed safety rules. ClearSend."
